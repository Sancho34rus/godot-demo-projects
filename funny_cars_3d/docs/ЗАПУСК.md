# Мир весёлых машинок 3D — запуск проекта

Проект написан на Godot 4.3 (GDScript), рендерер Compatibility, ориентация — альбомная.

## Как открыть
1. Установите Godot 4.3 (стабильная версия).
2. В Godot нажмите «Импорт», выберите файл `project.godot` в этой папке.
3. Нажмите ▶ (F5). Стартует главное меню `ui/main_menu.tscn`.

## Что уже есть
- Главное меню с кнопками: Поездка, Ферма, Стройка, Автомойка, Покраска, Ремонт, Гараж.
- Зоны: город, ферма, стройка, автогородок, природа (сцены в `worlds/`).
- Мастерские: автомойка, покраска, ремонт, гараж (`systems/`, `ui/garage.gd`).
- 20 машин в `core/vehicle_db.gd`, сохранение с резервной копией, русские голоса и процедурные звуки.

## Чего ещё нет
- Не проверено запуском: проект собран по коду, но ещё не прогнан в редакторе.
- Нет экспорта APK для Android: нужны Android SDK и шаблоны экспорта.
- Звуки генерируются скриптом `tools/gen_audio.py` (`python3 tools/gen_audio.py`).

## Браузерное демо
Отдельное упрощённое демо на three.js лежит в `../browser_demo/` и не является этой игрой.
